# Changelog

## 1.0.0

- Add Swift Package Manager foundation.
- Add Aquari client protocol core: transport, discovery, PKCE/OIDC, ID-token validation, refresh/UserInfo, Passport/signals, public Passport, and trust.
- Add Swift 6 conformance tests and clean-consumer build acceptance.

- Add Apple mobile adapter with `ASWebAuthenticationSession`.
- Add Keychain-backed token and authorization-transaction stores.
- Add restart-safe session restore, persisted refresh rotation, and sign-out cleanup.
